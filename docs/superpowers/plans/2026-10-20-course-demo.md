# 강의 시연 구현 계획

설계: `docs/superpowers/specs/2026-10-20-course-demo-design.md`.
사용자가 지정한 프런트·백엔드 서브에이전트 + 별도 worktree 방식을 사용한다. 현재 범위는 단순 시연이며 실제 DB·PG·권한 체계는 제외한다.

1. 메인: 비밀값·DB·가상환경·생성물 제외 Git 기준점과 별도 worktree2개 준비. 기존 인증 테스트를 기준으로 보존.
2. 백엔드 에이전트: 설계의 Course/API 계약대로 메모리 저장소·라우터·테스트를 작성하고 검증·커밋.
3. 프런트 에이전트: 계약 기반 강의 목록·상세·등록·테스트 구매·내 강의 화면 작성. Axios 로컬 의존성, 모바일·오류 상태 확인·커밋.
4. 메인: 각 커밋을 현재 체크아웃에 반영하고 전체 테스트 및 실제 Chrome 통합 확인. 발견한 오류만 수정하고 서버에 적용. DB 파일/스키마 변경 없음 확인, 결과 보고.

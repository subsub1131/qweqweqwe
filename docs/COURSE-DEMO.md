# 온라인 강의 시연

접속: http://127.0.0.1:8080/courses.html

벚꽃 콘셉트의 간단한 시연입니다. 모든 강의에서 샘플4개를 살펴보고 상세 창을 열 수 있습니다. 기존 로그인 페이지에서 일반/카카오 계정으로 로그인한 뒤 강의 화면으로 돌아오면 내 강의·강사 체험 등록을 사용할 수 있습니다. 구매 버튼은 현재 PortOne V2 테스트 PG 연동으로 교체되었으며, [결제 설정](PORTONE-SETUP.md) 후 이용합니다.

운영 결제·영상 재생·업로드·회원별 강사 권한은 구현하지 않았습니다. 현재는 로그인한 회원 누구나 강사 체험 폼을 사용할 수 있습니다. 강사 표시명은 한 명으로 고정합니다. 상품 목록은 메모리 기반이며 PortOne 주문·결제 상태는 별도 로컬 JSON 파일로 보존합니다. 결제에 사용한 강의 스냅샷도 복원합니다. 기존 DB 테이블·모델을 변경하지 않았습니다.

프런트는 Axios로 백엔드8000에 직접 요청합니다. 프런트8080은 정적 파일만 제공하며 API를 프록시하지 않습니다. 시크릿·JWT·쿠키 처리는 기존 백엔드에 유지합니다. `?debug=1`을 붙이면 메타데이터 로그를 사용할 수 있습니다. 강의·결제 API 경로를 로그에서 구분하며 개별 강의ID·URL 쿼리·요청/응답 본문은 기록하지 않습니다.

작업은 프런트·백엔드 각각 별도 관리 worktree에서 진행한 뒤 현재 프로젝트에 반영했습니다. 역할 지침은 `.codex/agents`를 따랐으며 유효하지 않은 모델명은 임의 수정하지 않고 실행 세션 모델을 상속했습니다.

검증: 전체 Python64개 통과. 임시 메모리 DB와 별도 프런트·백엔드, 실제 Chrome으로 익명 조회/구매 로그인 안내 → 가입/로그인 → 테스트 구매 → 내 강의 → 상품 등록/목록 반영을 확인했습니다. 모바일390px 가로 넘침 없음과 스크립트 오류 없음을 확인했습니다. 실제 사용자 DB에는 테스트 데이터를 넣지 않았습니다.
